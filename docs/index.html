Pulse

A music player for Android: search YouTube, YouTube Music and SoundCloud, play your own music, keep playlists and follow synced lyrics.

Install

  1. Download the APK with the button above, on your phone.
  2. Open the downloaded file. The first time, Android asks to allow installing apps from your browser or file manager: allow it, then tap Install.
  3. That's it. Pulse updates itself from then on: Settings → About → Updates.

Coming from the old Pulse?

  1. In the old app: Settings → Storage → Back up this profile.
  2. Uninstall the old app, then install this one.
  3. In the new app: Settings → Storage → Restore a backup. Playlists, favorites, history and settings come back.

What's in it

  • YouTube, YouTube Music, SoundCloud
  • Your own music files
  • Playlists and favorites
  • Synced lyrics, karaoke view
  • Speed, pitch, EQ presets
  • Sleep timer
  • Themes and backgrounds
  • Profiles for everyone
  • Plays with the screen off
  • No ads, no account

Requirements

  • Android 8.0 or newer, on a 64-bit phone (almost every phone from the last years).
  • Betas: Settings → About → Get beta versions to get bug fixes sooner.
