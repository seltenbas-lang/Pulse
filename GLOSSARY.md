# Glossary
| Term | Meaning | Rust name |
| --- | --- | --- |
| track | a song entry (title, artist, album, duration, addedAt, source URL) | `Track` |
| normalizeSearch | folds text for search (NFKD, strip marks, Arabic/Persian letter folding, lowercase) | `search_text::normalize_search` |
| sort mode | one of TRACK_SORT_MODES (manual, added-desc, …) | `SortMode` |
